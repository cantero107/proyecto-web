# Mi Web con GitFlow
Este proyecto es una práctica diseñada para aprender y aplicar GitFlow en un entorno de desarrollo.

## Estructura del proyecto
- `index.html`: Archivo principal con la estructura de la página.
- `css/style.css`: Estilos para la página web.

## Flujo de trabajo con GitFlow
1. Crear ramas para cada funcionalidad (`feature`).
2. Preparar una versión (`release`).
3. Corregir errores en producción (`hotfix`).

## Versión 1.0

Esta versión incluye las siguientes características:

### Mejoras visuales
- **Header con gradiente**: Implementación de un gradiente de colores que va desde un tono cálido (#FF6B6B) hasta un tono frío (#4B7BEC), mejorando significativamente la apariencia visual del encabezado.

### Contenido
- **Sección "Acerca de"**: Nueva sección que proporciona información sobre el proyecto y datos históricos sobre Jaume II el Just, con una estructura organizada en subsecciones.

### Funcionalidad
- **Formulario de contacto**: Implementación de un formulario completo en el footer que incluye campos para nombre, email y mensaje, permitiendo a los usuarios enviar consultas directamente desde la web.

### Mejoras técnicas
- Uso consistente de clases CSS para mantener un estilo coherente
- Optimización de la estructura HTML para mejorar la semántica
- Implementación de estilos responsive para mejor visualización en diferentes dispositivos
